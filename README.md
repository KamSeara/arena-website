# 🌐 Arena Saúde & Lazer

Official institutional website for **Arena Saúde & Lazer**, a company offering integrated solutions in **education, health, and leisure**.

Built with **HTML**, **CSS**, and **vanilla JavaScript**, the project focuses on **responsive design**, **performance**, and **accessibility** while showcasing the company's services through a clean and modern interface.

## ✉️ Contact Form

The contact form uses **FormSubmit** to send messages directly to the company's email without requiring a backend.

Before deploying, replace the placeholder email inside the form's `action` attribute.

```html
<form action="https://formsubmit.co/youremail@example.com" method="POST">
```
